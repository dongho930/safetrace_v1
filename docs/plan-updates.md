# 개발기획서 업데이트

2라운드 제출물 '개발기획서 업데이트본'을 만들 때 쓰는 원자료다. 기획서(`SafeTrace_개발기획서.docx`, git 밖)와 달라진 점, 보안 구조 설계, 일정 변경을 PR 마다 여기에 보탠다. 제출 직전에 기획서 해당 절로 옮긴다.

- **1절 보안 구조 설계**는 기획서 '2. 주요 기능 및 개발환경'(2.6·2.7)에 넣는다. 보안 평가 3순위 기준('보안약점을 감소하기 위한 구조적 설계')이 그 절을 본다. 3라운드 '보안구조설계 가점'의 근거이기도 하다.
- **2절 기획서와 달라진 점**은 해당 절에 변경 표시로 반영한다.
- 숫자는 측정한 것만 적고 출처(PR·평가 파일)를 단다.
